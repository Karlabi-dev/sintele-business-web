# SINTELE Business

> Perfil digital inteligente para empresas, equipes e projetos.

O SINTELE Business é uma solução do ecossistema SINTELE,
desenvolvida pela SivoDev, destinada à criação de perfis
digitais profissionais para empresas.

## 🎯 Objetivo

Permitir que empresas apresentem sua identidade, equipe,
projetos, serviços e canais de contato em um único perfil
digital.

## 🚀 Funcionalidades

- Perfil empresarial
- Logo e identidade visual
- Sobre a empresa
- Projetos e soluções
- Equipe
- Integração com perfis SINTELE User
- Redes sociais
- Site da empresa
- Contatos comerciais
- QR Code
- Compartilhamento
- Página pública acessível pela Web

## 🔗 Integração com o SINTELE

O SINTELE Business faz parte do ecossistema SINTELE.

Uma empresa poderá apresentar seus colaboradores,
e cada colaborador poderá possuir um perfil SINTELE User.

Exemplo:

Empresa
 ├── Projeto SINTELE
 ├── Projeto TRIP-PLANNER
 └── Equipe
      ├── Usuário 01 → SINTELE User
      ├── Usuário 02 → SINTELE User
      └── Usuário 03 → SINTELE User
